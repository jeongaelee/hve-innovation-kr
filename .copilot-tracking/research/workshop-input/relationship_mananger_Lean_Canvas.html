Why this fits — 시장·파트너 관점 근거 (가정)

반복 문의가 HR 업무를 잠식

HR팀 업무의 약 40%가 연차·급여·복리후생·증명서 같은 반복 문의 응대에 쓰인다는 가정에서 출발합니다. 자동화 효과가 즉시 체감되는 영역입니다.

M365 Copilot 확산의 첫 번째 Use Case

M365 Copilot을 도입한 고객이 “전 직원이 매일 쓰는” 업무 Agent를 찾고 있으며, HR 문의는 전사 사용자 기반의 대표 시나리오입니다.

반복 판매 가능한 IP

HR 규정 구조·온보딩 체크리스트는 산업·기업 간 공통성이 높아, 한 번 만든 Agent 템플릿을 Marketplace 구독 상품으로 반복 배포할 수 있습니다.

서비스 매출 결합

규정 학습·HR 시스템 연동·운영 개선을 구축 및 Managed Service로 붙여 구독 + 서비스 Mix로 수익성을 높일 수 있습니다.

Lean Canvas — HR Agent 솔루션 (HR 문의·온보딩 자동화)

1. Problem

  • HR팀 업무의 40%가 반복 문의 응대 (연차·급여·복리후생·증명서)
  • 신규 입사자 온보딩이 담당자마다 제각각
  • 규정 문서가 흩어져 있어 직원이 원하는 답을 못 찾음
  • 문의 유형·빈도가 데이터로 남지 않아 개선이 어려움

Existing Alternatives

  • 사내 포털 FAQ·규정 게시판
  • HR 담당자에게 이메일·메신저 문의
  • Excel 기반 온보딩 체크리스트
  • HRIS 자체 챗봇 (시나리오형)

4. Solution

  • HR 문의 Agent: 사내 규정 기반 Q&A (근거 문서 제시)
  • 온보딩 Agent: 입사 1~30일 체크리스트 안내·리마인드
  • 휴가·증명서 신청 자동 처리 (HR 시스템 연동)
  • 미해결 문의 HR 담당자 Handoff
  • 문의 분석 대시보드 제공

8. Key Metrics

  • HR 문의 자동 해결률 (목표 50%↑)
  • 평균 응답 시간: 1일 → 1분 이내
  • 직원 만족도 (CSAT)
  • 월간 사용자 수 (MAU)
  • Pilot → 전사 확대 전환율

3. Unique Value Proposition

“HR 문의, 24시간 Teams에서 즉시 답변” — 반복 문의 50%를 자동 해결하고, HR 담당자는 상담·인재 관리에 집중합니다.

High-level Concept

“모든 직원 곁의 AI HR 매니저.”

9. Unfair Advantage

  • 한국 노동법·HR 규정 맞춤 프롬프트·템플릿
  • 국내 주요 HR 시스템 연동 커넥터 보유
  • 개인정보 보호 설계·보안 검증 경험
  • 고객사 도입 레퍼런스 축적

5. Channels

  • Microsoft 세일즈 공동영업 (Co-sell)
  • HR 컨퍼런스·HR 커뮤니티
  • 무료 데모 → 1개 부서 Pilot
  • Teams 앱·Marketplace 등록

2. Customer Segments

  • 임직원 500~5,000명 규모 기업
  • 구매 결정: CHRO·HR 운영팀장
  • 실사용자: 전 임직원 + HR 담당자

Early Adopters

  • M365 Copilot을 도입했고 상반기 대규모 채용을 앞둔 기업

7. Cost Structure

  • Agent 개발·HR 시스템 연동 인건비
  • Copilot Studio·Azure OpenAI 사용료
  • 고객별 HR 규정 정비·데이터 준비
  • 보안·개인정보 검토 및 운영 지원

6. Revenue Streams

  • 초기 구축비: HR 규정 학습·시스템 연동 (6주)
  • 월 구독료: 임직원 1인당 과금 (Marketplace)
  • 추가 Agent 모듈 (평가 행정·교육·채용)
  • 연간 운영·개선 Managed Service

번호는 Lean Canvas 작성 권장 순서입니다 (Problem → Segments → UVP → Solution → Channels → Revenue → Cost → Metrics → Advantage).

핵심 검증 가설

  1. HR 문의의 절반 이상은 사내 규정 문서만으로 답변 가능한 반복 유형이다.
  2. 직원은 포털 FAQ보다 Teams 안의 대화형 Agent를 더 자주 사용한다.
  3. HR 리더는 “문의 자동 해결률”과 “응답 시간” 개선에 임직원 1인당 구독료를 지불할 의향이 있다.

MVP Scope & Demo Story

Included in MVP

  • 샘플 HR 규정 문서 (취업규칙·복리후생·휴가 규정) 기반 Q&A
  • 근거 문서 링크가 있는 답변
  • 신규 입사자 온보딩 체크리스트 안내
  • 휴가 신청 1개 시나리오 연동 (샘플 HR 시스템)
  • 미해결 문의 HR 담당자 Handoff
  • 문의 유형 분석 대시보드 초안

Excluded from MVP

  • 급여 계산·지급 등 민감 트랜잭션 처리
  • 인사 평가·선발 등 판단 업무
  • 모든 HRIS 벤더 연동
  • 다국어·해외 법인 규정

HVE Success Criteria

1. Validated Scenario

실제 HR 문의 맥락의 Persona(직원·HR 담당자)와 문제 1개를 명확히 정의

2. Buildable Architecture

데이터, Agent, 연동, 권한, 개인정보 보호를 포함한 설계

3. Working Prototype

Demo Flow를 끝까지 보여주는 동작 가능한 프로토타입

4. Two-week Backlog

Epic, User Story, Acceptance Criteria, 평가 질문 세트

5. Commercial Offer

구축비, 1인당 구독, 추가 모듈, Managed Service 가격 단위 가설

6. Customer Validation

최소 1개 고객과 문제·지불의향 가설 검증 일정 확보
